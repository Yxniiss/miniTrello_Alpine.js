# Mini Trello App (Alpine.js)

This project is a simple task management application inspired by Trello.

The goal of this project is to practice front-end development and learn how to use Alpine.js to create interactive web interfaces.

## Features

- Create tasks
- Move tasks between columns
- Simple task board interface
- Dynamic interactions with Alpine.js

## Technologies

- HTML
- CSS
- JavaScript
- Alpine.js

## Purpose

This project was created to practice JavaScript and learn how to build interactive interfaces using Alpine.js.

⚠️ This project is mainly a learning project and may not be fully optimized.
